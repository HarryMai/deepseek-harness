# @deepseek-ai/dsh-client-ui-settings-mcp

[English](README.md) | 中文

注册顶层的**自定义配置** Settings 分区，用于管理用户自己的 MCP 服务器。该分区排在**模型**与**Agent 预设**之后，绑定 Host 的 `mcp-client` settings namespace，并在用户保存前暂存编辑。用户可以在总开关关闭时保留任意数量的记录；每条新记录的独立开关默认关闭，只有两个开关都打开时 Host 才会加载该记录。保存时先写服务器记录再打开总开关，确保 Host 只协调目标配置。关闭总开关时会先保存它并卸载所有动态客户端，再更新仍被保留的记录。

每条记录可选**本地程序（stdio）**或 **Streamable HTTP**。本地表单包含服务名称、可执行文件或运行时命令、逐行参数和可选工作目录；本地安装的 CodeGraph 可执行程序就是一个例子。HTTP 表单包含服务名称和一个 `http:` 或 `https:` 端点。页面会在保存前标出不完整、格式错误或重复的已启用服务名称、命令和 URL，但会保留未完成的记录，以便用户之后继续填写。Host 会持久化总开关、记录和独立开关，并仍是验证和实时加载的权威。

页面还接受粘贴的 `mcpServers`、`mcp_servers` 或 `servers` JSON 映射、裸映射或单条记录。导入的记录只会加入草稿且默认关闭；导入绝不会改变总开关。由于此 settings 格式不能安全持久化，带有 `env` 或 `headers` 的内容会被拒绝。**测试连接**会把一条完整的暂存记录发送到仅限环回地址的 Host 端点。Host 会初始化临时客户端并列出工具，然后关闭客户端，因此测试不会保存或启用记录、注册工具，或启动重连循环。结果是临时的，只会报告工具数量或通用失败。

## 模型体验

无直接影响。该浏览器 settings 包只渲染暂存配置；Host 所有的 MCP 客户端负责每一项模型可见的工具注册。

#### KV Cache 影响

无直接影响。工具定义及其缓存影响由已加载的 MCP 客户端负责。

## 已知限制与暂缓事项

- **暂不支持凭据**——受 settings 驱动的管理器刻意不接受 stdio 环境变量或 HTTP 标头。带鉴权的记录在能够加载前需要专门的凭据引用设计。
- **只公开 Streamable HTTP**——传统 MCP HTTP／SSE 传输不是可选的记录类型。
- **本地程序由用户在 Host 上管理**——stdio 记录会直接启动可执行文件；应用不打包 CodeGraph 或其他 MCP 程序，它们也不会经过 harness shell 工具的沙箱策略。
