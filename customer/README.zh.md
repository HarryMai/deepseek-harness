# 个人定制功能

[English](README.md) | 中文

本目录集中记录个人分支相对 `upstream/master` 保留的功能，以及合并上游时需要核对的位置。功能实现仍由各自的代码和包文档维护；本目录不包含账号、密钥或个人机器的配置。

## 功能清单

| 功能 | 说明 | 与上游的关系 |
| --- | --- | --- |
| [MCP 设置](MCP_SETTINGS.md) | 在设置页管理、导入和测试 MCP 服务。 | 上游管理全局服务；此分支保留独立的会话级设置。 |
| [MCP 测试路由排查](MCP_SETTINGS_ROUTE_INCIDENT.md) | 诊断测试连接失败、路由挂载和本地程序的工作目录。 | MCP 设置的配套故障记录。 |
| [无证书桌面打包](UNSIGNED_DESKTOP_PACKAGING.md) | 本地无证书构建、签名模式选择和产物目录。 | 上游已有显式未签名构建；此分支扩展了模式选择和输出位置。 |
| [桌面启动与兼容](DESKTOP_COMPATIBILITY.md) | 使用现有工作区构建启动 Desktop，以及相关兼容性维护。 | 上游已有 Desktop；这里记录个人分支的差异。 |
| [模型请求兼容性设置](MODEL_REQUEST_COMPATIBILITY.md) | 在自定义模型供应商设置中调整请求兼容选项。 | 上游已有底层兼容配置；此分支增加设置页面控件。 |
| [Cordis 动态工具与参数兼容](CORDIS_COMPATIBILITY.md) | 保留临时动态插件工具，并恢复满足 schema 的 JSON 字符串参数。 | 上游已转向 Plugin Manager；合并时需核对是否继续保留。 |
| [分支 Agent Note 索引](BRANCH_AGENT_NOTES.md) | 查找本分支已有的决策记录。 | 部分记录描述历史实现或上游共有行为，不代表当前分支独有功能。 |

## 同步上游时

更新 `upstream/master` 后，将其与 `personal/feature-2026-10-03` 比较，核对各功能的实现、测试及文档，再调整本目录。上游若提供同等能力，先核对配置、数据兼容性和使用行为，再决定是否继续维护个人实现。

仓库的正式 Agent Note、包 README 和生成文档继续按仓库规则存放；它们可能记录通用决策或较早的实现，不能单独作为当前个人功能清单。涉及个人差异的决策记录从对应功能说明链接。
